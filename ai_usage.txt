AI USAGE DISCLOSURE
====================

This project was developed with the assistance of an AI coding assistant 
(Google Gemini / Antigravity IDE, Claude model), acting as a pair-programmer 
under my direct supervision and instruction.

What I did (My Contributions):
-------------------------------
- Designed the core language concept (gaming-themed emoji language "KaguLang").
- Enforced strict compliance with all assignment requirements (e.g., ensuring the 
  lexer was a pure hand-written state machine over bytes, not using regex).
- Conducted rigorous audits of the AST generation, EBNF grammar, and test coverage.
- Identified complex bugs (such as incorrect column counting for multi-byte UTF-8 
  emojis) and directed the AI to implement the specific logic to fix them.
- Specified the exact edge-case scenarios for the test suite (empty programs, 
  comments, multi-statement blocks, missing expressions) to ensure 100% coverage.
- Managed the repository, version control (git), and project structuring.

What I used AI for:
--------------------
- Translating my language design into the formal EBNF syntax (`grammar.ebnf`).
- Typing out the boilerplate for the AST class hierarchy in `compiler.py`.
- Writing the repetitive parts of the `run_tests.sh` bash script based on my requirements.
- Generating the `.expected` test dump files programmatically.
- Formatting the `README.md` documentation.
