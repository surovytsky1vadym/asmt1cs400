// top calls middle, middle calls bottom, nobody calls top: removing top
// leaves middle unused, removing middle leaves bottom unused.
// used is called once, so it is inlined; helper is called twice and stays.

🏟️

🏟️
🪄 top(n 🔫 💎32) ➡️ 💎32 🏟️
  🏁 middle(n) ➕ middle(n) ⚔️
🏟️

  🏁 n ✖️ n ⚔️
🏟️
